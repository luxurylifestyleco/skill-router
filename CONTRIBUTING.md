# Contributing

Thanks for improving Skill Router by [@luxurylifestyleco](https://github.com/luxurylifestyleco) at [VEDAXI](https://vedaxi.com).

Useful contributions include:

- realistic public routing fixtures;
- small adapters for agent hosts;
- measurable ranking improvements;
- privacy and security hardening;
- clearer integration documentation.

Keep the core platform agnostic. Do not add private skill inventories, provider credentials, telemetry, mandatory network calls, or automatic skill-script execution.

## Development

Node.js 18 or newer is required. There are no package dependencies.

```bash
npm test
npm run check
```

Every behavior change should include an observable test. Avoid tests that merely match headings or marketing copy.

## Pull requests

Explain the user problem, the behavior before and after, verification performed, and any privacy or compatibility impact. Keep unrelated changes out of the pull request.
